# Ретест багов

## Описание
Проведён ретест багов, найденных в ходе регрессионного тестирования веб-сервиса Mesto. Проверено, исправлены ли баги разработчиками.

## Что сделано
- Проверены 7 багов на тестовом стенде
- Проставлены статусы: «Закрыт» / «Переоткрыт»
- Оставлены комментарии с резолюцией о проверке

## Инструменты
- Google Таблицы
- Тестовый стенд Mesto

- Переоткрыто: 7
