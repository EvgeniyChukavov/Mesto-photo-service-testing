# Тест-кейсы для регрессионного тестирования

## Описание
Проведено регрессионное тестирование веб-сервиса Mesto по готовым тест-кейсам. Проверены: редактирование профиля, валидация полей, активность кнопки «Сохранить».

## Что проверялось
- Открытие окна редактирования профиля
- Обновление полей «Имя» и «Занятие»
- Отображение текста из блока пользователя в полях
- Валидация полей (мин/макс символов)
- Активность кнопки «Сохранить»
- Расположение окна редактирования
- Автоудаление пробелов

## Инструменты
- Google Таблицы
- Тестовый стенд Mesto

- Проведено 17 проверок
- Passed: 8
- Failed: 7
- Blocked: 2
