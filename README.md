# Тестирование фотосервиса Mesto

## О проекте
Проведено регрессионное тестирование веб-приложения Mesto и ретест найденных багов.

**Mesto** — это интерактивное веб-приложение (фотосервис), где пользователь может:
- добавлять фотографии с названием;
- оценивать фотографии лайком;
- удалять фотографии;
- редактировать профиль (менять имя и занятие).

## Что тестировалось
- Открытие/закрытие окна редактирования профиля
- Обновление полей «Имя» и «Занятие»
- Отображение текста из блока пользователя в полях
- Валидация полей (мин/макс количество символов)
- Активность кнопки «Сохранить»
- Расположение окна редактирования
- Автоудаление пробелов при сохранении

## Инструменты
- Тестовый стенд: https://code.s3.yandex.net/qa/files/mesto/index.html
- Google Таблицы — ведение тест-кейсов и баг-репортов
