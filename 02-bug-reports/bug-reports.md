## БР-1 — Обновление полей «Имя» и «Занятие» не работает

| Поле | Значение |
| :--- | :--- |
| **Приоритет** | Критический |
| **Статус** | Открыт |
| **Предусловие** | Открыто окно редактирования профиля |
| **Шаги** | 1. Кликнуть на строку ввода «Имя» 2. Ввести «Иван» 3. Кликнуть на строку ввода «Занятие» 4. Ввести «Художник» 5. Нажать «Сохранить» |
| **Ожидаемый результат** | На главной странице отображается «Иван» и «Художник» |
